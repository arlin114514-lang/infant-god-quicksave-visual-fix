快速存读档画面修复 1.0.1
适用：《幼神 Demo》Windows x64，Steam Build 25622697

安装与使用
1. 解压整个压缩包，双击“安装.cmd”。默认自动查找 Steam 安装位置。
2. 重启游戏，打开 Mod 列表，勾选“快速存读档画面修复”，并打开“加载 Mod”总开关。
3. 重新按 F5 保存一次，再用 F9 读取这份新快速存档。
4. 在 Mod 列表取消勾选即可停用，读档过程中会在操作完成后切换开关。

本包由小型代码加载前置和原生 Mods 目录下的独立修复模块组成。
可直接把整个 ZIP 发给其他玩家；不包含你的存档、账号配置或原版游戏程序。
已安装 BepInEx 5.x 的玩家会沿用现有前置，不覆盖其他插件和配置。
未安装前置的玩家会使用随包提供的官方 BepInEx 5.4.23.3 Mono x64。
无需覆盖 InfantGod.dll、UnityPlayer.dll 或游戏 exe。

1.0.1 更新
- 补上人物面板内“小判定提示”的清理，上一版仅完整处理了大判定窗口。
- 回收人物面板、读档恢复和后续帧都会拦住旧提示重新出现。
- 取消旧进度中尚未结束的被动检定，避免延迟回写；不改变成功失败结果。
- 新发生的判定仍正常显示，并按动画时长消失。
从 1.0.0 升级：再次运行本包安装器，重启游戏即可。此项修补兼容已有快速档，无须为清理判定框另存一次。

处理的问题
- 人物重建后再恢复状态、皮肤、像素动画及动画进度。
- 补存继承的场景背景与背景装扮状态。
- 补存人物局部位置、缩放、旋转、镜头尺寸及实际面板顺序。
- 清理读档前遗留的成功/失败过渡动画，防止判定字样盖在人物上。
- 补上没有活动剧情虚拟机时的直播人物恢复流程。
- 在检定尚未完成时按 F5，会提示预约，并在检定结束后保存；F9 取消预约。

旧存档说明
旧快速存档没有记录精确位置、继承背景和动画进度，无法凭空还原。
本包会尝试补恢复旧档已有的角色状态；完整恢复以启用后重新保存的快速存档为准。
新增画面数据内嵌在原快速存档 JSON 中，停用 Mod 后游戏仍能读取原有字段。
本包不回退剧情选择、不更改检定概率或成功失败结果，也不包含骰子裁决功能。

卸载
通常在游戏 Mod 列表中取消勾选即可。
移除本包文件：在 PowerShell 中运行：
  .\Uninstall.ps1 -GameRoot '你的游戏路径\Build'
卸载程序仅处理本包的记录文件，不删除共享前置、存档、其他 Mod 或备份。
