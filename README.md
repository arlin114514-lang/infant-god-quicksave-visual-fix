# 《幼神 Demo》快速存读档画面修复

修复快速读档后背景丢失、人物偏移或换位，以及判定提示残留等画面问题。

- 当前版本：**1.0.1**
- 适用版本：**《幼神 Demo》Windows x64，Steam Build 25622697**
- 本项目为非官方修复，与原作者无隶属关系。

## 下载

请前往 [Releases 发布页面](https://github.com/arlin114514-lang/infant-god-quicksave-visual-fix/releases) 下载完整安装包。

玩家安装请使用发布页附件中的 Mod ZIP；GitHub 自动生成的 Source code 压缩包主要用于查看源码。

## 安装与使用

1. 解压完整安装包，双击其中的 `安装.cmd`，安装器会尝试自动查找 Steam 游戏目录。
2. 重启游戏，在 Mod 列表中勾选“快速存读档画面修复”，并打开“加载 Mod”总开关。
3. 首次启用后，按 **F5** 重新保存一次，再按 **F9** 读取新快速存档。

已安装 BepInEx 5.x 的玩家会沿用现有前置；未安装前置的玩家可使用随包提供的运行组件。详细说明见安装包内的 `README.txt`。

## 主要修复

- 恢复人物状态、皮肤、动画及动画进度。
- 补存背景、人物位置、缩放、旋转、镜头尺寸及面板顺序。
- 清理快速读档前遗留的成功／失败判定提示。
- 补全直播状态下的人物恢复流程。
- 检定尚未结束时按 F5，会预约到检定结束后保存；F9 可取消预约。

**1.0.1** 进一步修复人物面板内的小判定提示残留，并处理旧被动检定的延迟回写。

## 注意事项

- 旧快速存档未记录的完整画面信息无法凭空恢复，建议启用后重新保存。
- 本 Mod 不改变检定概率或成功失败结果，不包含骰子裁决功能。
- 游戏更新或搭配其他 Mod 时可能需要重新验证兼容性。
- 在游戏 Mod 列表取消勾选即可停用；完整移除方法见安装包内说明。
